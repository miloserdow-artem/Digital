# DIGITAL

DIGITAL landing page — a training project created on November 15, 2021. 

This is my second educational layout. Throughout this project, I focused on mastering responsive web design across various devices, working with media queries, and building flexible grids.

## Features
- **Responsive Layout:** Correct display and layout adaptation on mobile devices, tablets, and desktops.
- **Clean Semantic HTML:** Use of semantic tags to improve web accessibility and SEO.
- **Modular CSS Structure:** Styles are organized by blocks for easier maintenance and scalability.
- **Visual Hierarchy:** A strong emphasis on typography and spacing to ensure comfortable content readability.

## Tech Stack
- HTML5
- CSS3

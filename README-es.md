# DIGITAL

Página de destino (landing page) DIGITAL: un proyecto de aprendizaje creado el 15 de noviembre de 2021.

Esta es mi segunda maqueta educativa. Durante el desarrollo, me enfoqué en dominar la adaptación de sitios web para diferentes dispositivos, el uso de media queries и la creación de rejillas (grids) flexibles.

## Características
- **Diseño adaptable:** Visualización correcta y fluida en dispositivos móviles, tabletas y ordenadores de escritorio.
- **HTML semántico limpio:** Uso de etiquetas semánticas para mejorar la accesibilidad web y el SEO.
- **Estructura CSS modular:** Los estilos están organizados por bloques para facilitar el mantenimiento y la escalabilidad.
- **Jerarquía visual:** Énfasis especial en la tipografía y los espacios para garantizar una lectura cómoda del contenido.

## Tecnologías
- HTML5
- CSS3

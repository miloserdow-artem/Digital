# DIGITAL
Лендинг‑сайт DIGITAL — учебный проект, созданный 15 ноября 2021 года. Это вторая учебная вёрстка: в ходе работы осваивал адаптацию сайтов под разные устройства.

## Особенности проекта
- Адаптивная вёрстка — корректное отображение на мобильных устройствах, планшетах и десктопах.
- Чистый семантический HTML — использование семантических тегов для улучшения доступности и SEO.
- Модульная CSS‑структура — стили организованы по блокам для удобства поддержки и масштабирования.
- Акцент на типографику и отступы — продуманная визуальная иерархия и комфортная читаемость контента.
##Технологии
- HTML5
- CSS3

Проект позволил закрепить навыки адаптивной вёрстки, работы с медиа‑запросами и построения гибкой сетки, а также уделить внимание деталям отображения на разных экранах.

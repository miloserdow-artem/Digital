# DIGITAL

Лендинг‑сайт DIGITAL — учебный проект, созданный 15 ноября 2021 года. 

Это моя вторая учебная вёрстка. В ходе работы над проектом я осваивал адаптацию сайтов под разные типы устройств, работу с медиа‑запросами и построение гибких сеток.

## Особенности проекта
- **Адаптивная вёрстка:** Корректное отображение на мобильных устройствах, планшетах и десктопах.
- **Чистый семантический HTML:** Использование семантических тегов для улучшения доступности и SEO.
- **Модульная CSS‑структура:** Стили организованы по блокам для удобства поддержки и масштабирования.
- **Визуальная иерархия:** Особый акцент на типографику и отступы для комфортной читаемости контента.

## Технологии
- HTML5
- CSS3
